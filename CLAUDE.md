# Samplit

Библиотека сэмплов с интеллектуальным поиском и мульти-аутом. Программная часть ВКР Алексашина А.А. (ВГТУ, бИВТ-232, научрук — Пачевский Д.Е.). Команда из трёх человек (Артем, Кирилл Шевченко, Ваня Разинков), движок общий, у каждого своя оболочка. Артем ведёт проект, ребята работают по задачам.

Общаемся по-русски, неформально. Артем в C++ и JUCE не силён, ребята тоже: объяснять коротко и по делу, код писать самому.

## Что делаем

Плагин (VST3, AU, Standalone). **Основной фокус (с 23.10.2026):** сэмплер уровня Kontakt, но с удобным роутингом, главный DAW — Cubase. Сэмплы раскладываются по клавишам piano roll: на одну клавишу — группа вариаций (хоть 50 клэпов), выбор по velocity-диапазонам и/или случайно (round-robin/random). Основной стерео-выход Main + опциональный мульти-аут (в Cubase выходы включаются нативно): набор сэмплов из каждой папки/группы уходит в свой аут, на аутах отдельные дорожки. Настройка аутов должна быть простой — это то, чем неудобен Kontakt.

**Продукт (со слов научрука, 23.10.2026):** готовый инструмент с барабанной библиотекой Пачевского. Установка записана на 7–10 микрофонов, каждый барабан слышен и на «чужих» микрофонах. Один удар = набор файлов по микрофонам, которые играют вместе и расходятся по мультиауту. Клавиша = барабан, вариации (место удара, сила, две палочки, кривой удар) выбираются по velocity и рандому. Пользователь выбирает готовый пресет и в маппинг не лезет (редактор остаётся только для нас, как служебный режим). Сэмплы с маппингом лежат в зашифрованных сжатых пакетах: базовый, средний, большой и отдельные (тарелки).

Библиотека (индексация, теги, поиск по описанию, «похожие») остаётся, но вторым приоритетом: сначала хороший сэмплер, потом умный поиск поверх него. Всё офлайн: на защите интернета нет.

- Стек: C++ / JUCE, CMake, SQLite, ONNX Runtime (для поиска по описанию).
- Платформы: Windows сейчас, macOS обязательно позже (Mac нет, вопрос с железом решим потом) — писать кроссплатформенно, без привязки к Windows.
- Тональность, нота, BPM и подобное — отдельная ветка допфункций (extras), не приоритет.

## Правила

- Аудиопоток: без аллокаций, блокировок и файлового ввода-вывода. Сэмплы грузятся в фоне и передаются в audio thread атомарной заменой.
- Ядро (`core/`) не зависит от JUCE GUI. Тяжёлое — в пул потоков.
- Мульти-аут: `BusesProperties` + `isBusesLayoutSupported`; Main + 16 выходов, группа (позже микрофон) → свой выход, режим «всё в Main», если DAW не включила выход. Микрофонов в библиотеке 15, все моно: решено перейти на 16 моно-выходов (ещё не сделано).
- Библиотека Пачевского: velocity выбирает конкретный удар, а не громкость; для неё громкость от velocity отключать, слой и вариацию выбирает плагин (`docs/library-structure.md`).
- Маппинг библиотеки берём только из `.nki` (утилита `tools/nki_extract.py`, готовые JSON в `sample_library/mapping/`). Не собирать удар по совпадению имён файлов в папках микрофонов: у части инструментов номера между микрофонами сдвинуты.
- Работа без сети: ничего не качать при запуске, модели и база локально. Лицензия: плагин работает по подписанному токену со сроком, сеть нужна только для его продления (в фоне, звук не блокирует); на защите токен выпускаем заранее. План: `docs/packs-plan.md`.
- Коммиты осмысленные, без упоминаний ИИ в коде, комментариях и истории. Комментарии в коде — по делу.
- Сэмплы в git не коммитить (`.gitignore`); тестовый набор лежит отдельно.

- Проект пересмотрен: основной продукт мультимикрофонный барабанный инструмент на библиотеке Studio600 (`docs/project-revision.md`), поиск и личная коллекция вторая очередь. Карточка, брендбук, обзор рынка и задачи в базе обновлены.
- Готово и закоммичено: сэмплер (клавиши, группы, зоны), 16 моно-выходов, модель и движок ударов (`plugin/Kit*`), формат пакета `.splpack` и сборщик `samplit-packer` (`core/pack`, `tools/packer`), токен лицензии и сервер (`core/license`, `tools/license_server`), разметка библиотеки (`tools/mark_kit.py`, `tools/kit-studio600.json`, `tools/presets`). 119 автотестов, pluginval 5, Python-тесты (разметка 14, сервер 20).
- Контракты: `docs/pack-format.md` (манифест, контейнер, токен), `docs/preset-format.md`, `docs/streaming-design.md` (стриминга в v1 нет, хвосты обрезаются при сборке, около 1,3 ГБ на пресет), `docs/packs-plan.md`.

## Сборка и проверка

- Сборка: `.\tools\build.ps1` (Debug), `-Config Release`. Перед сборкой закрыть Reaper и Samplit.exe: Windows не даёт перезаписать загруженный плагин.
- Тесты: `ctest --test-dir build\Debug --output-on-failure` или `build\Debug\tests\SamplitTests_artefacts\Debug\SamplitTests.exe`.
- pluginval: `~/tools/pluginval/pluginval.exe --strictness-level 5 --skip-gui-tests --validate <путь к Samplit.vst3>`.
- Устройство кода простым языком: `docs/architecture.md`, сборка и правила: `docs/development.md`, обзор рынка: https://claude.ai/artifact/MtrGSbQXofPqMEdgxfX7pS, брендбук: https://claude.ai/artifact/2rUTiaWbCMZ2JWh6MysCh2.
- Репозиторий на GitHub только на личном аккаунте владельца, организации вуза не трогаем.
