# Samplit

Мультимикрофонный барабанный инструмент и сэмплер с мульти-аутом: плагин для DAW (VST3, AU) и отдельное приложение. Установка записана на 15 микрофонов, один удар звучит как набор файлов по микрофонам, и каждый микрофон уходит на свою дорожку микшера. Пользователь выбирает готовый пресет и играет по клавишам. Сэмплы и маппинг лежат в зашифрованных сжатых пакетах, доступ по лицензии.

Программная часть ВКР (ВГТУ, бИВТ-232).

## Сборка (Windows)

Нужны Visual Studio с нагрузкой «C++ desktop», CMake, Ninja и Git.

```powershell
git clone --recurse-submodules <адрес репозитория>
cd samplit
.\tools\build.ps1            # Debug
.\tools\build.ps1 -Config Release
```

Скрипт сам подхватывает окружение Visual Studio. После сборки плагин копируется в `%LOCALAPPDATA%\Programs\Common\VST3`, отдельное приложение лежит в `build\Debug\plugin\Samplit_artefacts\Debug\Standalone\Samplit.exe`.

Тесты (Catch2, первая сборка скачает библиотеку):

```powershell
ctest --test-dir build\Debug --output-on-failure
```

Подробнее про сборку и проверку в DAW: [docs/development.md](docs/development.md).

## Структура

```
core/     ядро без графики: пакеты (pack), лицензия (license), индекс папок в SQLite
plugin/   плагин: процессор, движки (сэмплер и ударов), интерфейс
tests/    автотесты
tools/    сборка, разметка библиотеки, сборщик пакетов, сервер лицензий
brand/    логотип, палитра, шрифты, брендбук
docs/     документация
libs/     JUCE (git submodule)
```
