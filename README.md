# Samplit

**Samplit** — мультимикрофонный барабанный инструмент с готовыми пресетами и раздельными выходами микрофонов для DAW. Проект разрабатывается на C++/JUCE как программная часть ВКР ВГТУ; исходная аудиобиблиотека — Studio600.

Один MIDI-удар запускает синхронно связанные записи с нескольких микрофонов. Музыкант выбирает пресет и играет по клавишам, а микрофоны можно отправить на отдельные каналы микшера DAW без ручного построения маппинга. Служебный редактор сэмплов и зон предназначен для разработчиков, не для обычного пользователя.

## Что предусмотрено

- VST3 и Standalone на Windows; AU и сборка на macOS — **план**, а не подтверждённый релиз.
- Main (стерео) + до 16 дополнительных **моно**-выходов. Если отдельный выход не активирован в DAW, звук попадает в Main.
- Клавиши и зоны velocity, слои, вариации ударов, выбор случайно / по кругу / по velocity; сохранение параметров в проекте DAW.
- Пресеты барабанной установки, микшер микрофонов (уровень, панорама, Solo/Mute, назначение выходов).
- Упакованные сэмплы `.splpack` (FLAC и шифрование), проверяемые подписанные лицензии и офлайн-воспроизведение.
- Интеллектуальный поиск по личной коллекции — **вторая очередь**, не функциональность текущего барабанного MVP.

## Сборка (Windows)

Понадобятся MSVC с компонентом Desktop development with C++, CMake, Ninja, Git и подмодуль JUCE.

```powershell
git clone --recurse-submodules <URL_репозитория>
cd samplit
.\tools\build.ps1
.\tools\build.ps1 -Config Release
```

Если репозиторий уже есть, но JUCE не загружен:

```powershell
git submodule update --init --recursive
```

> Перед пересборкой закройте Samplit.exe и DAW с загруженным плагином: Windows может блокировать DLL/VST3.

Тесты после Debug-сборки:

```powershell
ctest --test-dir build\Debug --output-on-failure
```

Инструкции по среде, проверкам, `pluginval` и установке пакетов — в [docs/development.md](docs/development.md). Передача сборки научному руководителю — в [docs/delivery.md](docs/delivery.md). Инструкции DAW — в [docs/daw/](docs/daw/).

## Структура проекта

| Каталог | Назначение |
|---|---|
| `core/` | Ядро без GUI: индекс, упаковка, лицензирование и общие компоненты |
| `plugin/` | JUCE-плагин, аудиодвижок, загрузчик и интерфейс |
| `tools/` | Сборка, разметка, пакер, сервер лицензий, снимки UI, дистрибутив |
| `tests/` | Тесты C++ и вспомогательные тесты |
| `libs/` | Внешние библиотеки, включая JUCE |
| `docs/` | Документация и история решений |
| `brand/` | Визуальные материалы, если присутствуют в репозитории |

Полная карта документации: [docs/README.md](docs/README.md).
