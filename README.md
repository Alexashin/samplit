# Samplit

Библиотека сэмплов с интеллектуальным поиском и мульти-аутом: плагин для DAW (VST3, AU) и отдельное приложение. Указываешь папки со своими сэмплами, плагин индексирует их, ставит теги и находит звук по описанию («драйвовый 808»). Сэмплы раскладываются по пэдам, и каждый пэд уходит на свой стерео-выход, то есть на свою дорожку микшера DAW. Всё работает офлайн.

Программная часть ВКР (ВГТУ, бИВТ-232).

## Сборка (Windows)

Нужны Visual Studio с нагрузкой «C++ desktop», CMake, Ninja и Git.

```powershell
git clone --recurse-submodules <адрес репозитория>
cd samplit
.\tools\build.ps1            # Debug
.\tools\build.ps1 -Config Release
```

Скрипт сам подхватывает окружение Visual Studio. После сборки плагин копируется в `%LOCALAPPDATA%\Programs\Common\VST3`, отдельное приложение лежит в `build\Debug\plugin\Samplit_artefacts\Debug\Standalone\Samplit.exe`.

Тесты (Catch2, первая сборка скачает библиотеку):

```powershell
ctest --test-dir build\Debug --output-on-failure
```

Подробнее про устройство проекта, сборку и проверку в DAW: [docs/development.md](docs/development.md) и [docs/architecture.md](docs/architecture.md).

## Структура

```
core/     ядро без графики: индекс сэмплов в SQLite (позже анализ, теги, поиск)
plugin/   плагин: процессор, движок пэдов, браузер сэмплов, интерфейс
tests/    автотесты
tools/    скрипты сборки и вспомогательные утилиты
brand/    логотип, палитра, шрифты, брендбук (исходники и скрипты сборки)
docs/     документация
libs/     JUCE (git submodule)
```

В `core/` пока только индекс папок; анализатор, теги и поиск по описанию добавятся позже.
