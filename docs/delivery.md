# Передача сборки Пачевскому

Передаём Release, не Debug. Лицензия выдаётся ключом без сервера, всё делается скриптами.

## Что делаем мы

```powershell
.\tools\build.ps1 -Config Release          # плагин, приложение, packer
> **29.10.2026:** окно лицензии скрыто в плагине (`kLicenseUi = false`): вводить ключ в интерфейсе сейчас нельзя. Токен кладут файлом (`make_dist.ps1 -License <файл>`), для проверяющего основной путь — режим «Моя библиотека…» без лицензии. Описание ключа и окна ниже относится к варианту, когда лицензионный интерфейс будет включён.

.\tools\install_packs.ps1 -All               # все пакеты кроме unverified (по умолчанию), пакеты, пресеты, токен на этот компьютер
.\tools\make_dist.ps1                      # dist\Samplit-<версия>\ и .zip (около 1 ГБ: пакет studio600-unverified в архив не кладётся)
.\tools\make_dist.ps1 -Lite                # без пакетов, архив в несколько МБ: звук из WAV-папки кнопкой «Моя библиотека…»
```

Лицензию выписываем один раз и отдаём **ключом**, который вставляют в окно плагина, либо файлом, который выбирают кнопкой «Выбрать файл». Сервера и интернета для этого не нужно. Установщик лицензию сам не ставит.

Архив для проверяющего (28.10.2026, Пачевский Д.Е.) собирается так: ключ выписан через `make_token.py` в `dist\licenses\pachevsky`, затем

```powershell
.\tools\make_dist.ps1 -LicenseFolder dist\licenses\pachevsky   # папка «Лицензия» (license.token + license.key.txt) и Инструкция.pdf
```

Папка `Лицензия` лежит рядом с установщиком, но `Установить.cmd` её не читает: лицензию вводят вручную. `Инструкция.pdf` берётся из `tools\dist\Инструкция.pdf` (копия: `docs\samplit-instruction.pdf`), собирается из `guide.html`:

```powershell
& "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe" --headless=new --no-pdf-header-footer --print-to-pdf=tools\dist\Инструкция.pdf "file:///<путь>/dist/Samplit-<версия>/Инструкция.html"
```

(HTML берут из собранного дистрибутива, чтобы нашлись картинки `setup\img`.)

Служебный ключ для демонстрации (любой компьютер, 60 дней). Если обёртка падает с «usage», вызовите `make_token.py` напрямую (команда в `docs/development.md`):

```powershell
.\tools\issue_license.ps1 -User "Пачевский Д.Е." -AnyMachine
```

Рядом с `license.token` появится `license.key.txt`: одна строка `SPL1-…` (около 2 КБ, имя и срок зашиты внутрь). Её отправляем отдельно от архива. Бессрочный служебный ключ плагин отвергает.

| Файл в архиве | Зачем |
|---|---|
| `Установить.cmd` | ставит VST3, приложение, пакеты, пресеты |
| `Data\presets` | три кита Studio600 и папка `mixes` (два микса). Служебные `studio600-full-*` в архив не попадают |
| `Инструкция.html` | установка, лицензия, Cubase, мульти-аут, раскладка клавиш |

## Как отдать

1. Архив залить в облако (Яндекс Диск, Google Drive) и отправить ссылку.
2. Пачевский распаковывает, закрывает Cubase и запускает `Установить.cmd` (права администратора не нужны).
3. Открывает Samplit, вставляет присланный ключ в поле «Ключ лицензии», нажимает «Активировать». Плагин сохраняет лицензию в свою папку, ключ или файл после этого не нужен.
4. Вместо ключа можно прислать файл `license.token`: кнопка «Выбрать файл» в том же окне.

Привязанная к компьютеру лицензия (на случай, если понадобится): `.\tools\issue_license.ps1 -Code "win:...:..." -User "..."`. Для себя: `.\tools\issue_license.ps1 -User "Алексашин А.А."`.

## Чего нельзя делать

- Не класть в архив `~\.samplit-license` (ключ подписи, ключи пакетов, база лицензий) и `license.token` с нашего компьютера. Служебный ключ на 60 дней в папке «Лицензия» для проверяющего допустим.
- Не отдавать пакеты без лицензии посторонним: они зашифрованы, но ключ в лицензии, а лицензию мы выписываем сами.
- Debug-сборка (с служебным режимом и отладкой) Пачевскому не уходит.

## Когда появится сервер

Лицензия по сети (`SAMPLIT_LICENSE_URL`, `core/src/License*.cpp`, `tools/license_server`) заменит `issue_license.ps1`. Формат токена и пакетов не поменяется, поэтому установленные у Пачевского файлы продолжат работать.
