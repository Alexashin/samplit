# Передача сборки Пачевскому

Передаём Release, не Debug. Лицензия выдаётся ключом без сервера, всё делается скриптами.

## Что делаем мы

```powershell
.\tools\build.ps1 -Config Release          # плагин, приложение, packer
.\tools\install_packs.ps1 -Packs <все пакеты, включая studio600-unverified>   # пакеты, пресеты, токен на этот компьютер
.\tools\make_dist.ps1                      # dist\Samplit-<версия>\ и .zip (около 1,5 ГБ)
```

Лицензию выписываем один раз и отдаём **ключом**, который вставляют в окно плагина. Сервера и интернета для этого не нужно. Архив ключа не содержит.

Служебный ключ для демонстрации (любой компьютер, 60 дней):

```powershell
.\tools\issue_license.ps1 -User "Пачевский Д.Е." -AnyMachine
```

Рядом с `license.token` появится `license.key.txt`: одна строка `SPL1-…` (около 2 КБ, имя и срок зашиты внутрь). Её отправляем отдельно от архива. Бессрочный служебный ключ плагин отвергает.

| Файл в архиве | Зачем |
|---|---|
| `Установить.cmd` | ставит VST3, приложение, пакеты, пресеты |
| `Инструкция.html` | установка, лицензия, Cubase, мульти-аут, раскладка клавиш |

## Как отдать

1. Архив залить в облако (Яндекс Диск, Google Drive) и отправить ссылку.
2. Пачевский распаковывает, закрывает Cubase и запускает `Установить.cmd` (права администратора не нужны).
3. Открывает Samplit, вставляет присланный ключ в поле «Ключ лицензии», нажимает «Активировать». Плагин сохраняет лицензию в свою папку, ключ или файл после этого не нужен.
4. Вместо ключа можно прислать файл `license.token`: кнопка «Выбрать файл» в том же окне.

Привязанная к компьютеру лицензия (на случай, если понадобится): `.\tools\issue_license.ps1 -Code "win:...:..." -User "..."`. Для себя: `.\tools\issue_license.ps1 -User "Алексашин А.А."`.

## Чего нельзя делать

- Не класть в архив `~\.samplit-license` (ключ подписи, ключи пакетов, база лицензий) и `license.token` с нашего компьютера.
- Не отдавать пакеты без лицензии посторонним: они зашифрованы, но ключ в лицензии, а лицензию мы выписываем сами.
- Debug-сборка (с служебным режимом и отладкой) Пачевскому не уходит.

## Когда появится сервер

Лицензия по сети (`SAMPLIT_LICENSE_URL`, `core/license`, `tools/license_server`) заменит `issue_license.ps1`. Формат токена и пакетов не поменяется, поэтому установленные у Пачевского файлы продолжат работать.
