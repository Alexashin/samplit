# Передача сборки Пачевскому

Передаём Release, не Debug. Лицензия выписывается один раз на его компьютер и бессрочная; сервера пока нет, всё делается скриптами.

## Что делаем мы

```powershell
.\tools\build.ps1 -Config Release          # плагин, приложение, packer
.\tools\install_packs.ps1 -Packs <все пакеты, включая studio600-unverified>   # пакеты, пресеты, токен на этот компьютер
.\tools\make_dist.ps1                      # dist\Samplit-<версия>\ и .zip (около 1,5 ГБ)
```

Архив без лицензии: код компьютера у Пачевского неизвестен заранее. В архиве есть:

| Файл | Зачем |
|---|---|
| `Установить.cmd` | ставит VST3, приложение, пакеты, пресеты; в конце показывает код компьютера и кладёт его в буфер обмена и в файл на рабочем столе |
| `Код компьютера.cmd` | то же самое отдельно, если код понадобится позже |
| `Установить лицензию.cmd` | на него перетаскивают присланный `license.token` |
| `Инструкция.html` | установка, лицензия, Cubase, мульти-аут, раскладка клавиш |

## Как отдать

1. Архив залить в облако (Яндекс Диск, Google Drive) и отправить ссылку. В мессенджер такой файл не пройдёт.
2. Пачевский распаковывает, закрывает Cubase и запускает `Установить.cmd`. Установщик прав администратора не просит.
3. Он присылает код компьютера (одна строка вида `win:...:...`).
4. Мы выпускаем файл лицензии один раз:

```powershell
.\tools\issue_license.ps1 -Code "win:...:..." -User "Пачевский Д.Е."
```

Файл появится в `dist\licenses\<имя>\license.token`. Отправляем его отдельно от архива (лицензия привязана к его компьютеру, на другом не откроется).
5. Он перетаскивает `license.token` на `Установить лицензию.cmd`. Всё: пакеты открыты, пресеты работают без интернета.

Для себя то же самое: `.\tools\issue_license.ps1 -User "Алексашин А.А."` кладёт бессрочную лицензию на этот компьютер.

## Чего нельзя делать

- Не класть в архив `~\.samplit-license` (ключ подписи, ключи пакетов, база лицензий) и `license.token` с нашего компьютера.
- Не отдавать пакеты без лицензии посторонним: они зашифрованы, но ключ в лицензии, а лицензию мы выписываем сами.
- Debug-сборка (с служебным режимом и отладкой) Пачевскому не уходит.

## Когда появится сервер

Лицензия по сети (`SAMPLIT_LICENSE_URL`, `core/license`, `tools/license_server`) заменит `issue_license.ps1`. Формат токена и пакетов не поменяется, поэтому установленные у Пачевского файлы продолжат работать.
