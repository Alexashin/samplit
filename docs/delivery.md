# Передача сборки Пачевскому

> Решение 12.11: покупатели (владельцы и новые) получают звук как WAV-библиотеку; `.splpack` служит только установщику (быстрое скачивание, распаковка в WAV с маппингом), плагин работает без лицензии. Установщик с распаковкой пока не сделан; см. `user-stories.md`.

Передаём Release, не Debug. С 29.10.2026 **лицензия отложена**: плагин собирается без неё (флаг `SAMPLIT_LICENSE=OFF`, по умолчанию), никаких ключей и токенов получатель не вводит. Звук берётся из папки WAV (`00-Studio600ru-Drum-LIB`) кнопкой «Моя библиотека…». Код лицензии и пакетов `.splpack` остался в репозитории и в тестах, но в плагине выключен; вернуть его можно сборкой с `-DSAMPLIT_LICENSE=ON`.

## Что делаем мы

```powershell
.\tools\build.ps1 -Config Release          # плагин, приложение, packer
.\tools\make_dist.ps1 -Lite                # dist\Samplit-Drummer-<версия>\ и .zip без пакетов, несколько МБ
```

В архив попадают плагин VST3, Standalone, данные установки (Setup из 12 мест, пресетов и миксов нет), манифесты `Data\manifests` (раскладка ударов без звука) и `Инструкция.html` / `Инструкция.pdf`. Полный вариант `make_dist.ps1` без `-Lite` дополнительно кладёт пакеты `.splpack` (около 1 ГБ), но при выключенной лицензии плагин их не читает; он нужен только для сборки с `SAMPLIT_LICENSE=ON`.

`Инструкция.pdf` берётся из `tools\dist\Инструкция.pdf` (копия: `docs\samplit-instruction.pdf`) и собирается из `guide.html`:

```powershell
& "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe" --headless=new --no-pdf-header-footer --print-to-pdf=tools\dist\Инструкция.pdf "file:///<путь>/dist/Samplit-<версия>/Инструкция.html"
```

(HTML берут из собранного дистрибутива, чтобы нашлись картинки `setup\img`. После правки `guide.html` PDF нужно собрать заново и скопировать в `docs\samplit-instruction.pdf`.)

| Файл в архиве | Зачем |
|---|---|
| `Установить.cmd` | ставит VST3, приложение и манифесты |
| `Data\manifests` | раскладка ударов для режима «Моя библиотека…» |
| `Инструкция.html` / `.pdf` | установка, подключение библиотеки, Cubase, мульти-аут, раскладка клавиш |

## Как отдать

1. Архив залить в облако (Яндекс Диск, Google Drive) и отправить ссылку.
2. Получатель распаковывает, закрывает Cubase и запускает `Установить.cmd` (права администратора не нужны).
3. Открывает Samplit, нажимает «Моя библиотека…» и выбирает папку `00-Studio600ru-Drum-LIB` (WAV-файлы остаются на его диске, плагин читает их по месту; хвосты длинных ударов подгружаются с диска во время игры, SSD предпочтительнее HDD).
4. Настраивает места установки (Setup) и играет. Если что-то идёт не так (файл не читается, диск не успевает), строка статуса плагина показывает предупреждение с именем файла.

## Чего нельзя делать

- Не класть в архив `~\.samplit-license` (ключ подписи, ключи пакетов, база лицензий) и `license.token` с нашего компьютера.
- Не отдавать сэмплы библиотеки посторонним без согласия правообладателя.
- Debug-сборка Пачевскому не уходит.

## Когда лицензию вернут

Вернуть можно пакеты `.splpack` с лицензионным токеном: сборка с `-DSAMPLIT_LICENSE=ON`, выпуск токена `.\tools\issue_license.ps1 -User "…" [-Code "win:…:…"]` (токен привязывается к компьютеру; служебного токена «для любого компьютера» больше нет), пакеты и ключи — `install_packs.ps1`. Лицензия по сети (`SAMPLIT_LICENSE_URL`, `core/src/License*.cpp`, `tools/license_server`) заменит `issue_license.ps1`. Формат токена и пакетов не менялся.

## Хранение релизов (с 23.11.2026)

Готовые дистрибутивы на диске не копим: каждый zip выкладывается в GitHub Releases (репозиторий приватный) и после проверки загрузки удаляется из `dist/`.

```bash
git tag vX.Y.Z && git push origin main --tags
gh release create vX.Y.Z dist/Samplit-Drummer-X.Y.Z.zip -R Alexashin/samplit -t "Samplit Drummer X.Y.Z" -n "что нового"
gh release view vX.Y.Z -R Alexashin/samplit --json assets    # сверить размер
```
Лимит GitHub: 2 ГБ на файл. Старые версии (до 0.3.2) называются `Samplit-X.Y.Z.zip`.
