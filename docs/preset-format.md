# Формат пресета (v1) и дополнения к манифесту

Пресет решает, что играет и как звучит, и не содержит ключей и аудио: лежит рядом с пакетами открытым JSON. Пример: `tools/presets/studio600-default.json`. Контракт пакетов остаётся в `docs/pack-format.md`.

## Пресет

| Поле | Что значит |
|---|---|
| `format` | версия формата, сейчас 1 |
| `id`, `name` | идентификатор и название для списка пресетов |
| `comment` | короткое описание под названием в списке пресетов (необязательно). Пресеты, сохранённые пользователем кнопкой «Сохранить как…», лежат рядом как `user-*.json` и помечены «Мой» |
| `packs` | какие пакеты нужны (по `id` пакета). Нет пакета или лицензии на него: барабаны этого пакета молчат, в интерфейсе показываем «нужен пакет» |
| `pieces` | какие барабаны играют (по `id` барабана из манифестов). Нужен, чтобы выбирать вариант малого: в пакетах три малых барабана на одних и тех же клавишах |
| `mix` | id микса по умолчанию (файл в `presets/mixes`). Если поля нет, берётся блок `mics` пресета (старый формат). Выбранный пользователем микс переносится на следующий кит |
| `includeUnverified` | брать ли удары с `unverified: true` (пакет `studio600-unverified`). По умолчанию `false` |
| `select.mode` | `live` или `kontakt` (см. ниже) |
| `select.layerSpread` | для `live`: на сколько слоёв вверх и вниз от найденного по velocity может уйти выбор. 0 = только свой слой |
| `select.noRepeat` | не играть тот же удар два раза подряд на одной клавише |
| `select.velocityToGain` | вклад velocity в громкость: 0 = нет (так у библиотеки Studio600, динамика записана в самих ударах), 1 = линейно как у обычного сэмплера |
| `select.pick` | правила выбора удара внутри слоя по барабанам и клавишам, см. ниже. Каждое правило даёт переключатель на схеме установки (вкладка «Установка») |
| `mics.<id>` | по микрофону: `level` (дБ), `pan` (-1…1, действует на сведение в Main), `out` (выход 1…16, выход 0 = Main), `mute` |

Микрофоны моно. Невключённый в DAW выход играет в Main, `pan` и `level` применяются только к Main-миксу.

Пресеты Studio600 в `tools/presets`: три основных (`studio600-default` Ahead Live, `studio600-ahead-low`, `studio600-ambasador`) и три полных (`studio600-full-live`, `-low`, `-hi`), названия «[Проверка] …», в дистрибутив не копируются: к основному набору добавлены пакет `studio600-unverified`, `includeUnverified: true` и барабан `cymbals_x` (тарелки C7–G#7). Полные нужны для проверки с Пачевским, спорные места собраны в `docs/open-questions.md`.

## Пресет (кит) и микс

Пресет отвечает за то, **что играет**: пакеты, барабаны, малый, правила выбора удара. Микс отвечает за то, **как сведено**: уровень, панорама, выход и mute каждого микрофона. Они независимы: микс меняется мгновенно, без перезагрузки кита, и остаётся при смене кита.

Миксы лежат в `presets/mixes/*.json` рядом с пресетами (в репозитории `tools/presets/mixes`):

```json
{ "format": 1, "id": "mix-multiout", "name": "Мульти-аут (DAW)", "comment": "…",
  "mics": { "kick_in": { "level": 0.0, "pan": 0.0, "out": 1, "mute": false } } }
```

`out`: 0 = Main, 1…16 = моно-выход. Готовые: `mix-balanced-main` («Стерео в Main», все микрофоны в Main) и `mix-multiout` («Мульти-аут (DAW)», микрофон на свой выход 1–15). Уровни и панорамы поставлены вручную «на слух», из Kontakt они не пришли (в `.nki` готовых миксов нет). Пользовательские миксы сохраняются как `user-*.json` (кнопка «Микс» → «Сохранить текущий микс…»), существующие файлы не перезаписываются. Имя текущего микса и признак «изменён» хранятся в проекте DAW.

## Режимы выбора удара

- **`kontakt`**: velocity выбирает ровно тот удар, у которого `velLo..velHi` содержит velocity. Если окно пустое, молчим. Так играет исходный инструмент Kontakt.
- **`live`**: по velocity находим слой (окно из `layers`), внутри слоя берём случайный удар, не равный предыдущему (`noRepeat`), при `layerSpread` > 0 слой может смещаться на соседний. Velocity между слоями (в «пустых» значениях библиотеки) попадает в ближайший слой.
- Слои с `pick: "exact"` (сбивки, крещендо, дроби, закрывание хэта) в `live` не рандомизируются: velocity выбирает конкретный удар, как в Kontakt. Для закрывания хэта velocity означает темп трека.

## Выбор удара внутри слоя (`select.pick`)

Только для режима `live`. Массив правил, поздние перекрывают ранние:

```json
{ "name": "Хэт C2–F#4", "pieces": ["hat"], "keys": [48, 78], "mode": "random", "includeExact": true }
```

| Поле | Что значит |
|---|---|
| `name` | подпись переключателя на экране кита |
| `pieces` | барабаны по `id` |
| `keys` | `[от, до]`, номера клавиш включительно; без поля правило на все клавиши барабана |
| `mode` | `random`: случайный удар без повтора подряд (с разбросом `layerSpread`); `cycle`: по кругу, с первого удара слоя (по возрастанию velocity) до последнего и снова, счётчик свой у каждой клавиши и слоя; `exact`: velocity выбирает конкретный удар, как в Kontakt |
| `includeExact` | по умолчанию слои с `pick: "exact"` из манифеста (сбивки, крещендо, закрывание хэта) правило не трогает; `true` перекрывает и их |

Пользователь меняет режим на схеме установки (вкладка «Установка», клик по барабану), выбор сохраняется в проекте по ключу `барабаны:клавиши`; новый кит начинает круг сначала.

Значения в стандартных пресетах Studio600 (со слов Пачевского, 23.10.2026): бочка по кругу (случайного выбора нет); хэт C2–F#4 случайно, с возможностью переключить на круг; все крэши по кругу, кроме C1 и E1 (спокойное состояние, одиночные удары, там `exact`). Остальное (малый, томы, райд, чайна, сплеш) пока случайно, как было.

## Дополнения к манифесту пакета

`tools/mark_kit.py` кладёт в манифест несколько необязательных полей сверх `docs/pack-format.md`. Читающий код должен их пропускать, если они не нужны:

| Где | Поле | Значение |
|---|---|---|
| слой | `key` | клавиша слоя (слои привязаны к клавише, id вида `k26_120_127`) |
| слой | `label` | короткое название динамики или приёма: `strong`, `medium`, `crescendo`, `roll-cuts`… |
| слой | `pick` | `"exact"`, если velocity выбирает удар точно; по умолчанию поля нет (случайный внутри слоя) |
| слой, удар | `peerGroup` | удар или слой из группы `-D` Kontakt; смысл этой группы не подтверждён |
| слой, удар | `unverified` | окно или клавиша не описаны в руководстве либо с ним расходятся; такие удары лежат в `studio600-unverified` под тем же `id` барабана |
| удар, слой | `id` слоя | у удара поле `layer` ссылается на слой, у слоя есть `velLo`, `velHi` |
| файл удара | `end` | абсолютный отсчёт конца обрезки. В `.nki` конец задан от конца файла (отрицательное число), сборщик переводит по длине WAV |

Пакеты складываются по `id` барабана и `id` удара: `studio600-unverified` добавляет к `kick`, `snare_live`, `hat` и другим непроверенные удары.

## Сборка манифестов

```
python tools/nki_extract.py <файл.nki> --out sample_library/mapping/<имя>.json     # один раз на .nki
python tools/mark_kit.py --check                                                  # проверка, ничего не пишет
python tools/mark_kit.py                                                          # sample_library/packs-src/<пакет>.json
```

Ручная разметка: `tools/kit-studio600.json` (микрофоны, пакеты, барабаны, названия слоёв и признак `verified`). Три `.nki` (Ahead-LIVE, Ahead-LOW, Ambasador-NEW) отличаются малым барабаном, поэтому малый собран тремя пакетами `studio600-snare-live`, `-low`, `-hi`, а остальная установка берётся из ED-Ahead-LIVE.
