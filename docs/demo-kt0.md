# Показ КТ0 (23.10): сценарий

Цель: за 5–7 минут показать, что каркас продукта работает: папка → сэмплы → прослушивание → пэды → каждый пэд на своей дорожке DAW.

## Подготовить заранее

- Собрать Release: `.\tools\build.ps1 -Config Release`. Плагин скопируется в `%LOCALAPPDATA%\Programs\Common\VST3`.
- Папка с сэмплами на ноутбуке: настоящий набор или `python tools/make_test_samples.py`.
- Reaper: проект с дорожкой Samplit и 8 дорожками-приёмниками (выходы Out 1…8 разведены по дорожкам), на 2–3 дорожках разные эффекты (например, ReaEQ и ReaVerbate), чтобы было слышно, что пэды обрабатываются отдельно.
- Выключить Wi-Fi: всё работает офлайн.

## Сценарий

1. **Что это.** Библиотека сэмплов для продюсера: поиск по своей коллекции и раскладка по пэдам с отдельными выходами. Всё локально, без облака и подписок.
2. **Браузер.** «Выбрать папку» → список появляется сразу, сканирование в фоне. Набрать в поиске `kick` или `808 dirty`: фильтр по словам.
3. **Прослушивание.** Стрелками по списку: каждый сэмпл звучит, снизу волна.
4. **Пэды.** Перетащить kick, snare, hat, 808 на пэды 1–4 (или Enter: на свободный пэд). Кликнуть по пэдам.
5. **Настройки пэда.** Выбрать 808, покрутить высоту и громкость.
6. **Мульти-аут.** В Reaper сыграть пэды: каждый звучит на своей дорожке, видно по индикаторам. Включить эффект на дорожке снейра: меняется только снейр. На пэде видна подпись `OUT N`.
7. **Сохранение.** Сохранить проект, закрыть, открыть: пэды и настройки на месте.
8. **Качество.** 35 автотестов, проверка pluginval на строгости 5, сборка и тесты на GitHub Actions при каждом коммите.
