# Пакет правок Samplit для Claude Code

1. `SAMPLIT_FEEDBACK_SPEC.md` — подробное ТЗ, приоритеты, критерии приёмки.
2. `CLAUDE_CODE_PROMPT.md` — готовая инструкция для запуска работы.
3. `reference/pravki.docx` — исходное сообщение заказчика с оригинальными изображениями.
4. `reference/screenshots/` — 7 скриншотов, извлечённых из оригинального DOCX и привязанных к пунктам ТЗ.

Рекомендуется распаковать папку в репозиторий, например в `docs/feedback/2026-11-14/`, затем открыть Claude Code в корне проекта и вставить текст из `CLAUDE_CODE_PROMPT.md` (пути при необходимости адаптировать).
