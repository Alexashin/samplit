# Решения и разногласия по документации

Этот документ фиксирует **актуально принятые решения** по состоянию на 29.10.2026 и отмечает более ранние варианты. При изменении решений сначала подтвердить фактическую реализацию и тесты.

| Вопрос | Действующее решение | Ранее / что не переиспользовать |
|---|---|---|
| Основной продукт | Готовый барабанный инструмент Studio600 с пресетами | Менеджер собственной коллекции и сетка 8 пэдов — исторический прототип |
| MIDI | Клавиши, velocity-слои, правило выбора удара `select.pick` | Старое фиксированное соответствие MIDI 36–43 восьми пэдам |
| Выходы | Main стерео + 16 **моно**; 15 микрофонов, запасной выход | Main + 8 стерео / Main + 16 стерео в ранних прототипах |
| Единство удара | Одновременный запуск всех его микрофонов по `.nki` | Поиск соответствий по числовым именам файлов (некорректно) |
| Звук и память | Звук без потерь: float32 (24 бит), без int16 и обрезки хвостов (требование владельца библиотеки, 29.10). Длинные WAV из папки («Моя библиотека…») стримятся с диска (`DiskStreamer`, голова 0,35 с); пакеты `.splpack` пока целиком в RAM | Решение v1 от 24–28.10 (int16, обрезка тихих хвостов, без стриминга) **отменено** |
| Лицензия | **Отложена (29.10):** по умолчанию выключена (`SAMPLIT_LICENSE=OFF`), звук только из WAV-папки; код токенов и пакетов сохранён для будущего. Служебного токена «на любой компьютер» нет | Сетевое продление и пакеты под токеном не считать включёнными |
| Пользовательский UI | Кит и микс (независимы), схема установки с режимами удара и громкостью барабана, микшер; лицензии в интерфейсе нет | Редактор пэдов/зон — лишь служебный режим Debug |
| Проверка | C++/Python-тесты, `pluginval`; Cubase — отдельно | Успех старого Reaper с пэдами не означает проверку нынешнего мультимикрофонного роутинга |
| Roadmap | `current-status.md` + рабочие задачи в `project-card.md` | Старые пункты «сделать» из `project-revision.md`/`packs-plan.md` — снимки прошлого |

## Где находится подробное основание

- Технические контракты: `pack-format.md`, `preset-format.md`, `library-structure.md`.
- Измерения памяти и стриминг и режим «Моя библиотека…»: `streaming-design.md`.
- История изменения продукта: `project-revision.md`.
- Очередь задач и этапов: `project-card.md` (статусы снимка сверять с `current-status.md`).

В документации есть записи разных моментов 23–24 октября. Они сохранены как источники проектной истории, но помечены там, где больше **не задают текущую реализацию**.
