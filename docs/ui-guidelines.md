# Правила интерфейса Samplit (Д4)

Утверждено 12.11.2026 (макет `docs/mockups/ui-mockup-v1.html`, решения Д3 в `ui-redesign.md` §11). Новую функцию сначала относим к ярусу (§2), потом выбираем место. Исходные решения и исследование: `ui-redesign.md`.

## 1. Визуальная система «студийный прибор»
Замечание пользователя к макету v1: «чуть детский / нейронный». Поэтому:
- Радиусы 3–4 px (`brand::radiusS/radiusM`), линии 1 px, сетка 4 px. Без больших скруглений, переключателей-«таблеток», пунктирных плиток.
- Графитовые поверхности `bg → surface → pad → raised2`, один акцент ультрамарин: заливка `accent #4d75ff` (максимум одна главная кнопка на экран, включённое состояние), текст и тонкие линии `accentText #aac5ff`. Радужных цветов групп нет: барабаны различаются подписью и формой, цвет только у состояния (выбран, звучит, выключен).
- Шрифты вшиты в плагин (OFL, `plugin/assets/fonts`): IBM Plex Sans (текст, веса Regular и Medium) и JetBrains Mono (числа, клавиши). Заголовки разделов: Medium 11,5 px прописными с разрядкой. Geologica из брендбука остаётся для логотипа и сайта: в окне плагина она выглядела мягко и «детски».
- Крутилка: тёмный корпус, тонкая дуга значения, риска-указатель, цифры моно. Фейдер: узкий паз, плоская ручка с риской, шкала дБ (только микшер). Светодиодная кнопка `LedButton`: подпись и LED. Без градиентов, свечений, теней.
- Размеры: текст ≥ 12 px, кликабельное ≥ 28 px, контраст текста ≥ 4,5:1. Текст и контролы не уменьшаются вместе с рисунком установки.

## 2. Ярусы и места (куда класть новую функцию)
| Ярус | Что | Где |
|---|---|---|
| На виду | Установка, выбранный барабан, Играть/Стоп/Цикл, «Перетащить в Cubase», статус | Страница «Барабаны» и мини-полоса |
| Под рукой | Параметры барабана, редактор партии, живость, микшер, клавиатура | Панель барабана, страницы «Партия» и «Микшер», сворачиваемая клавиатура |
| В кладовке | Папка, файлы установки, режимы, группы, карта силы, файлы партии, справка | «Установка ▾», ⚙, «Подробнее», «⋯», «?» |

Места под будущее (каркас закладываем сразу, список страниц и разделов расширяется одной строкой):
| Будущее | Место |
|---|---|
| Поиск по личной коллекции, сэмплы, теги (вторая очередь) | 4-я страница «Звуки» в строке страниц (страницы заводятся списком `PageId` + фабрика) |
| Новые библиотеки и наборы (L1) | «Установка ▾», раздел «Библиотека» |
| Лицензия (если включим) | ⚙ раздел «Лицензия» и индикатор справа в шапке, скрыт при `SAMPLIT_LICENSE=OFF` |
| Новые настройки поведения, выходов, папки | ⚙ «Настройки»: список разделов, раздел добавляется без перевёрстки |
| Новые параметры барабана | «Подробнее» в панели барабана: стопка раскрывашек |
| Грувы, пресеты Logical Editor (T7), файлы партии | «⋯» у партии |
| Фоновые задачи (загрузка, сканирование, установщик T4) | Строка статуса: очередь сообщений с приоритетом и прогрессом |
| Pack Builder (T8), служебное | ⚙ «Служебное» (только в служебном режиме) |

## 3. Жесты (одинаковые везде)
Тянуть вверх/вниз; Shift: точный шаг; двойной клик по крутилке/фейдеру: сброс; двойной клик по числу: ввод; колесо: малый шаг; правый клик: «Сбросить»; Tab и стрелки с видимым фокусом. **Сила удара по высоте клика: ниже = сильнее** (одно правило на схеме и на клавиатуре).

## 4. Слова
Установка (весь набор), барабан (не «место»), звук (не «пак»; `title` без префикса «Studio600 Drum LIB: »), удар, сила (число в подсказке и «Подробнее»), громкость барабана ≠ уровень микрофона.

## 5. Компоненты (`plugin/ui/`)
`Knob` (крутилка 48/32 px с подписью и значением, ввод числа двойным кликом), `Fader` (микшер), `LedButton`, `SegmentedControl`, `DisclosureHeader`, `drawSectionCaption`; общий вид стандартных контролов JUCE в `plugin/LookAndFeel.h`; токены в `plugin/Brand.h`; шрифты `plugin/ui/Fonts.h`. Галерея: `samplit-snapshot <папка> --components` → `00-components.png`.

## 6. Проверка вида
Снимки `samplit-snapshot` в Compact 920×560, Standard 1120×640, Expanded 1400×800; читать PNG, сверять с §1. Вживую в Cubase при 1920×1080 @125% проверяет пользователь.
