## Уже внесено

- Пустые значения velocity теперь дают тишину во всех режимах выбора удара. `Случайно` и `По кругу` выбирают записи только внутри назначенного слоя; `По velocity` требует точного попадания. Пустое значение не продвигает счётчик цикла.
- Удалены блок «Попробовать: сила удара», его кнопки и громкость отдельного барабана, включая сохранение `PIECE` в новом состоянии плагина. Старое состояние с `PIECE` загружается с игнорированием этого узла. `select.layerSpread` старых пресетов читается, но больше не влияет на звук и не сохраняется.
- Переименованы выходы и микрофоны по их назначению, исправлены публичные названия томов по стабильным ID без изменения аудиомаппинга. Шестнадцатый выход оставлен резервным `Out 16`.
- Перестроена схема установки как вид сверху по изображению преподавателя. Второй `Ride 18″` показан как декоративный элемент: звучащий ride один. Обновлены синтетический кит для снимков, часть документации, пресеты и тесты.
