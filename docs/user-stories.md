# Сценарии пользователя и покрытие

Контрольная точка: 28 октября 2026 (закрытие этапа интерфейса и пресетов). Статус проверен по коду и 153 автотестам, **живая проверка в Cubase 15 и на чистой Windows не выполнялась**. Связанные документы: [project-card.md](project-card.md) (US14–US20, задачи t*), [preset-format.md](preset-format.md).

Роли: **барабанщик-продюсер** (основная, Cubase), **преподаватель/эксперт** (проверка и защита), **владелец** (выдаёт лицензии).

## Модель пресетов

- **Кит** = какой малый + пакеты + правила выбора удара. Грузится с диска (~3 с в Release).
- **Микс** = уровень, панорама, выход, mute микрофонов. Применяется мгновенно, переживает смену кита.
- Из Kontakt (`.nki`) пришли раскладка клавиш, окна velocity, варианты малого, 15 микрофонных каналов. Готовых миксов в `.nki` нет: уровни и панорамы подобраны вручную, их нужно подтвердить на слух.

4. Подтверждение миксов на слух и ответы Пачевского по группам `-D` и тарелкам C7–G#7 ([open-questions.md](open-questions.md)).
