# Сценарии пользователя и покрытие

Контрольная точка: 29 октября 2026, сценарии с пресетами и миксами обновлены 11.11.2026 (установка из мест, `setup-spec.md`); Cubase 15 проверен **частично** (`current-status.md`), чистая Windows не проверялась. Связанные документы: [project-card.md](project-card.md) (US14–US20, задачи t*), [setup-spec.md](setup-spec.md).

Роли: **барабанщик-продюсер** (основная, Cubase), **преподаватель/эксперт** (проверка и защита), **владелец** (выдаёт лицензии).

## Модель установки (с 11.11.2026)

- **Установка** = 12 фиксированных мест Studio600 на своих клавишах. У места: вкл/выкл, пак (звук) подходящего типа, громкость, режимы выбора удара по группам. Пресетов и миксов нет.
- Замена пака или вкл/выкл места перезагружает кит через кэш клипов: остальные места не перечитываются, старый кит звучит до готовности нового.
- «Сделать стандартной» сохраняет установку для новых экземпляров, «Сброс» возвращает стандартную, «Вернуть заводскую» (с подтверждением) удаляет стандартную и берёт заводскую.
- Из Kontakt (`.nki`) пришли раскладка клавиш, окна velocity, варианты малого, 15 микрофонных каналов.
