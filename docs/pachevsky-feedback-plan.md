## Что просили (кратко)
1. Бочка: 4 разных звука разнести; все бочки на C0 с выбором (настройка «выбор бочки»); пак бочки называть по микрофону (D12, D6, Rode, U87).
2. Схема: райд ниже, неактивный (декоративный) райд убрать; Crash 18 на место райда, Crash 16 на место Crash 18, China справа сверху, Splash левее, альты выше.
3. Выбор инструмента: у каждого места на схеме можно выбрать пак (звук), включить/выключить; новых мест не добавляем, только замена на месте (например, будущий набор тарелок Пачевского ставится вместо Crash 18).
4. Админский генератор паков с понятным UX для человека без программирования.
5. Мульти-аут: Over, Room, альты (томы) стерео-выходами, чтобы в DAW не делать стерео руками.
6. Вкладка с настройками инструмента.
7. Маппинг и режимы выбора ударов по заметке (хэт, бочка, малый, креши, альты, райд, чайна, сплеш).
8. «Нововведения» (бэклог): проникновение/bleed, хуманайз, логический MIDI-редактор, конвертер маппинга, piano roll маппинга, обучающий режим, умный помощник по сбивкам/крещендо.

## Принятые решения (не пересматривать без причины)
- **Пресетов больше нет** (ни китов, ни миксов): слишком сложно. Установка = фиксированные места Studio600 на своих клавишах; у места: вкл/выкл, выбранный пак из установленных, громкость, режимы выбора.
- Хранение: в проекте DAW; кнопки «Сделать стандартной» (старт новых экземпляров) и «Сброс».
- Миксы заменяем переключателем «Выходы: Стерео / Мульти-аут» + фейдеры.
- Бочка: одна клавиша C0 (MIDI 24, C3=60), 4 пака по микрофону (папки `KICK-PM-D12`, `-D6-OLD`, `-RODE-OUT`, `-U87-OUT`); клавиши 21–23 свободны. Подписи «пластик/фетр» были непроверенными.
- Малый на A0–B0: ставим малый, A0 режим exact; состав A#0/B0 сверить по `.nki` (в заметке противоречие: «нет малого A0/B0» и «A0 вручную»). Пачевский пришлёт настройки Kontakt для сверки.
- Стерео-шины: Over, Room, Toms (4 тома с панорамой по схеме); остальное моно: Kick In, Kick Out, Snare Top, Snare Bottom, Hat, Ride, Room Mid. Старые проекты Cubase потеряют разводку выходов (0.2.x, пользователей нет).
- Velocity: числа как в Kontakt (совместимость партий, парные удары на одинаковых velocity у разных инструментов). Группы velocity (между пробелами, например 120–127 / 111–118): режимы «по кругу/случайно» работают внутри группы. Поверх чисел добавляем **смысловую разметку** слоя: `label` (человеческое имя), `role` (`main/ghost/fill/roll/crescendo/rimshot/choke`…), `pair` (парная группа другого инструмента, например крещендо малого G#0 ↔ крещендо альтов). Это фундамент для будущего умного помощника (ВКР): по MIDI-партии находить крещендо/сбивки и дописывать парный инструмент одной кнопкой.
- UX: считать, что пользователь ничего не знает; всё должно быть понятно по наитию, подписи человеческие, подсказка одной фразой.
- Генератор паков: отдельное JUCE-приложение (Samplit Pack Builder), в плагин не попадает.
- Объём: «Нововведения» только в бэклог.

## Режимы выбора по заметке (значения по умолчанию в манифестах паков)
- Хэт C2–G4 по кругу (можно «случайно»); A4 exact (вручную). Бочки по кругу.
- Малый: D0 75–127 по кругу; C#0, D#0, F#0, G0 по кругу; 51–73 на D0/D#0/E0/F0 exact (дроби, вручную); D0 26–49 по кругу; E0/F0 сбивки случайно внутри группы; G#0 42–73 крещендо exact на одинаковых velocity с альтами (нарисовал крещендо на малом, скопировал на альт); A0 exact; A#0/B0 по кругу в группе (после сверки).
- Crash C#1–D#1 и F1–G1 по кругу; C1 и E1 exact. China G#1, A1, A#1 exact. Splash B1 exact.
- Альты: по кругу внутри групп velocity; крещендо (C6, D6, E6, F#6; velocity 42–73) exact. Автораспределение крещендо отложено.
- Райд: по кругу C5, C#5, D5, D#5, F#5, G5, G#5, A#5, B5; exact E5, F5, A5.
- Расхождения заметки и руководства (крещендо альтов F#6 vs G#6; дроби «C0, C#0» vs E0/F0) записать в `open-questions.md`, делаем по заметке.
