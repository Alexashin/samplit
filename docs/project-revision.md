# Пересмотр проекта (24.10.2026)

Основание: научрук передал барабанную библиотеку Studio600 (Пачевский Д.Е., студия Studio600), объяснил идею продукта, из `.nki` библиотеки снят полный маппинг. Это меняет логику и подход. Старая постановка: менеджер сэмплов с ИИ-поиском и пэдами. Новая: готовый мультимикрофонный барабанный инструмент.

## Что было и что стало

| Тема | Было | Стало |
|---|---|---|
| Продукт | Библиотека пользователя: указал папки, плагин индексирует, ищет словами, раскладывает по пэдам | Готовый инструмент: пользователь выбирает пресет, играет по клавишам, получает микс и микрофоны по выходам. Маппинг от него скрыт |
| Единица звука | Сэмпл на пэде | **Удар**: клавиша + velocity, набор моно-файлов по микрофонам (кик и снейр 8 микрофонов, томы 10, тарелки 5–6) |
| Выбор звука | Пэд играет свой сэмпл | Velocity выбирает слой и удар. В библиотеке одно значение velocity = один записанный удар, громкость от velocity не меняется. Режимы: «как в Kontakt» (точное соответствие) и «Живой» (слой по velocity, удар случайный, без повтора подряд) |
| Выходы | Main + пэд N → стерео-выход N | Main (стерео-микс) + 16 моно-выходов, **микрофон = выход**. Невключённый в DAW выход играет в Main |
| Данные | Индекс папок в SQLite | Зашифрованные сжатые **пакеты** `.splpack` (FLAC, XChaCha20-Poly1305), манифест с маппингом, пресеты. Маппинг выгружается из `.nki` утилитой `tools/nki_extract.py` и размечается вручную. Пакеты: base / mid / large и дополнения (тарелки) |
| Лицензия | Не рассматривалась | Подписанный токен (Ed25519), срок 7 или 30 дней, ключи пакетов внутри токена, привязка к машине, сервер выдачи и продления. Плагин работает офлайн по токену |
| Память | Не критично | Библиотека 12,3 ГБ WAV 24 бит. Стриминг хвостов тарелок (2–30 с) с диска обязателен |
| Умный поиск, теги, ONNX | Ядро проекта | Вторая очередь: поиск по описанию и «похожие» поверх готового инструмента. Смысл «интеллектуальности» в новой постановке нужно согласовать с научруком |
| Редактор групп и зон | Основной интерфейс | Служебный режим для нас (разметка, отладка на слух), в релизе скрыт |
| Главная DAW | Reaper, затем остальные | Cubase 15 (основная), Reaper, затем остальные. Cubase, Kontakt 8, Reaper на компьютере разработчика установлены |
| Документ прав | Нет | `LICENSE`: аудио принадлежит Пачевскому Д.Е. и Studio600, код только по разрешению автора |

## Что уже сделано (на 24.10.2026)

- Сэмплер на клавишах, группах и зонах: диапазоны клавиш и velocity, режимы «все слои», «по кругу», «случайно», выход у каждой группы (Main и 16 стерео), сохранение в проекте DAW. 50 автотестов, pluginval 5 SUCCESS.
- Статический рантайм MSVC: Cubase падал на компьютере со старой `msvcp140.dll`.
- Разбор библиотеки (30 396 WAV, моно 24 бит 44,1 кГц) и руководства пользователя, полный маппинг из `.nki` (16 226 зон, 2 361 удар, 21 группа-микрофон).
- План пакетов, лицензии и движка: `docs/packs-plan.md`.
- Прежнее: индекс папок в SQLite (`core/`), браузер, waveform, прослушивание.

3. Формат пакета и сборщик (`core/pack`, `samplit-packer`), шифрование.
4. Разметка поверх выгрузки из `.nki`, первые примерочные пакеты, пресет.
5. Загрузка пакетов в плагине, int16 в памяти, стриминг хвостов.
6. Интерфейс: пресеты, микшер микрофонов, служебный режим.
7. Лицензия: токен, проверка, сервер, продление.
8. Уровни пакетов (mid, large), дополнения.
9. Проверка в Cubase, Reaper, pluginval; macOS.
10. Поиск по описанию, «похожие» (вторая очередь).

## Открытые вопросы

- Остаётся ли в ТЗ ВКР «интеллектуальный поиск» и в каком виде (ТЗ пишет Пачевский, срок 16.11).
- Смысл групп `-D` в `.nki` (огибающая, глушение, выход); смысл клавиш малого A0, A#0, B0 и тарелок на C7–G#7.
- Условия распространения: форматы пакетов, сроки лицензий, кто выпускает токены (согласовать с Пачевским).
- Mac для AU и Logic.
