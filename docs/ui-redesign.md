# Переделка интерфейса Samplit (T10): решения, исследование, план

Контрольная точка: **12.11.2026, ночь.** Документ — единственный источник по T10 для следующей сессии: всё обсуждение с пользователем сведено сюда. Исходные данные: аудит окна `ux-plan.md` §1–2 (план U1–U8 оттуда **отменён**), исследование рынка `UX_audit_drum_VST3_2026-11-12.md` (сделано GPT по нашему промпту, с источниками), снимки окна `build\snap\*.png` (Debug 12.11).

## 1. Почему

Пользователь проверил плагин в Cubase 15: звук и перетаскивание MIDI работают, но интерфейс «нагруженный и неудобный», «нет чёткой структуры, кнопки везде натыканы и смешаны по темам», «не интуитивный». Окно 1180×780 не влезает в ноутбук 1920×1080 при масштабе Windows 125% (логически 1536×864). Причина (оценка пользователя, согласна с аудитом): функции и суть продукта сильно поменялись с начала разработки (пэды → мультимикрофонный Studio600 с установкой, партией и перетаскиванием в DAW), а каркас окна старый; новое добавлялось кнопками в свободные места.

Принцип пользователя (дословно по смыслу): **как в квартире, куда притащили много вещей: разложить по удобным местам хранения. То, что используется постоянно, на виду; что не используется, не мозолит глаза, но всегда интуитивно понятно, где лежит.** Переделка может быть радикальной.

## 3. Что показало исследование

Подробно и с источниками: `UX_audit_drum_VST3_2026-11-12.md`. Главное:
- У лидеров дом = изображение установки, клик по барабану выбирает и прослушивает; 3–5 страниц по задачам (EZdrummer 3: Drums / Grooves / Grid Editor / Mixer). Toontrack сознательно ограничивает число настроек.
- Жалобы пользователей: одни и те же инструменты в нескольких местах (BFD3; **у нас то же: вкладки «Установка» и «Инструменты»**), мелкие незаметные элементы и текст (BFD3, SD3), окно не масштабируется или не влезает на ноутбук (BFD3.5, SSD5 до 5.5, NI), крутой порог входа (SD3, BFD3), неясно, что регулируется — барабан или микрофон (GGD), безымянные выходы в Cubase (у нас выходы уже названы, `.drm` есть).
- Ключевой антипаттерн: **не показывать одновременно детальную установку, 15 фейдеров и редактор партии.**
- Для картинки рекомендован детальный 2D-вектор: каждый барабан отдельная группа с крупной зоной клика (детализация рисунка не дробит зону клика), hover = контур и имя, клик = прослушивание, выбор = постоянная подсветка, удар от MIDI = короткая вспышка, выключенный барабан затемнён, но выбирается.

## 4. Раскладка функций по частоте использования

| Ярус | Что | Где лежит |
|---|---|---|
| **На виду всегда** | Установка (клик играет и выбирает), какой барабан выбран; Играть/Стоп, Цикл, такты; **«Перетащить в Cubase»**; ход загрузки и ошибки одной строкой | Страница «Барабаны» + мини-полоса партии внизу неё |
| **Под рукой (1 клик, всегда в одном месте)** | Выбранный барабан: вкл, звук, громкость барабана (крутилка), прослушать; полный редактор партии; живость (2 крутилки + «другой вариант»); микшер микрофонов; клавиатура | Панель барабана справа; страница «Партия»; блок «Живость» на «Партии»; страница «Микшер»; полоска клавиатуры внизу |
| **В кладовке (меню с понятным названием)** | Папка звука; стандартная/заводская установка, сброс, файл установки; «velocity = сила / номер записи», «повторяемо / живой выбор»; группы ударов и их режимы, карта силы; файлы партии (json, mid); Стерео/Мульти-аут; справка | Меню **«Установка ▾»** (всё про набор барабанов), **⚙ «Настройки»** (поведение плагина), **«Подробнее»** в панели барабана, **«⋯»** у партии, **«?»** |
| **Убрать** | Подсказка внизу схемы, стул на схеме, id паков (`studio600-snare-live`) и ноты/окна velocity в подписях, плашка «Партия → Cubase» в строке вкладок, вкладка «Инструменты», кнопки «Удар: плагин» и «Повторяемо» в строке вкладок, «Обновить список паков» (автоматически при выборе папки; в меню только в служебном режиме) | — |

Словарь (одни слова везде, и в `guide.html`): **установка** = весь набор барабанов; **барабан** вместо «место»; **звук** вместо «пак» (показывать `title` без префикса «Studio600 Drum LIB: »); **удар** = одна запись; **сила** вместо velocity в обычных подписях (число — в подсказке и «Подробнее»); **громкость барабана** (место) ≠ **уровень микрофона** (микшер).

## 5. Целевая структура (к макету)

Основа: вариант A «Kit-first» из исследования = наш «Три комнаты».

```
[логотип] [Установка: стандартная ▾]   Барабаны | Партия | Микшер        [⚙] [?]
Барабаны: детальная векторная установка          | панель барабана: вкл, звук,
          (клик играет и выбирает, высота клика  | громкость (крутилка), прослушать,
           = сила)                               | ▸ Подробнее: группы, режимы, карта силы
          мини-полоса: [▶] [Цикл] Такты 1–4 ……………………… [⇢ Перетащить в Cubase]
Партия:   транспорт, сетка 1–4 такта (строки = барабаны, подписи словами), «Живость» (крутилки), «⋯» файлы
Микшер:   каналы сгруппированы по барабанам (Бочка, Малый, Томы, Тарелки, Комната): фейдер, крутилка панорамы, M/S, выход; Стерео/Мульти-аут
[▾ Клавиатура]  сворачивается на любой странице
```

- «Установка: стандартная / изменена» вместо имени пресета (пресетов нет, решение 11.11); меню «Установка ▾» с сохранением и файлами.
- Второй вариант для сравнения в макете: «как EZdrummer 3» — установка сверху, полоса партии снизу на одном экране. Вариант «партия в центре» снят.
- Первый запуск: если папка не выбрана — экран «Выберите папку звука» (3 шага: папка → нажмите барабан → нарисуйте партию и перетащите). Если установщик T4 сразу запишет путь библиотеки, первый звук без выбора папки.
- «Нет звука»: строка статуса различает причины (папка не выбрана, барабан выключен, Mute/Solo, MIDI не приходит).

## 6. Визуальная система

- Логотип как есть (`lockuphondark_svg` в BinaryData). Два направления палитры в макете: акцент из логотипа (голубой `#7ca1ff`) и тёплый «ламповый»; выбрать одно. Один акцент, графитовые поверхности 3 уровней. Без градиентов, свечения, стекла, теней на всём, эмодзи (anti-slop из глобального `CLAUDE.md`).
- Шрифт с кириллицей под OFL, не Inter/Geist (кандидаты IBM Plex Sans, Manrope, Onest; подобрать `ui-ux-pro-max --domain typography`), вшить в BinaryData.
- Компоненты: крутилка (большая 48 px, малая 32 px; подпись и значение), фейдер (только микшер), переключатель, сегменты, кнопки трёх уровней (главная / обычная / тихая), поле числа с перетаскиванием (темп), меню-кнопка, плитка перетаскивания, заголовок раздела, раскрывашка.
- **Жесты (единые везде):** тянуть вверх/вниз; Shift — точный шаг; двойной клик по контролу — сброс; двойной клик по числу — ввод; колесо — малый шаг; правый клик — меню «Сброс»; Tab и стрелки с видимым фокусом. Сила удара по высоте клика **одинаково** на схеме и на клавиатуре (сейчас на клавиатуре «ниже = сильнее»; выбрать одно правило в макете).
- **Размеры:** Compact 920×560, Standard 1120×640 (по умолчанию), Expanded 1400×800 + свободное растяжение; при первом открытии не больше рабочей области экрана (`Desktop::getDisplays().getPrimaryDisplay()->userArea`) с запасом на рамку Cubase; размер запоминается (аддитивное свойство состояния, старые версии игнорируют). Текст не мельче 12 px, кликабельное не ниже 28 px, контраст ≥ 4.5:1; текст и кнопки не уменьшаются вместе с рисунком установки.

## 10. Открытые вопросы

1. Источник рисунка установки: есть ли у Пачевского фото его установки?
2. Палитра: голубой акцент логотипа или тёплый (решается по макету).
3. Сила удара по высоте клика: «выше = сильнее» или «ниже = сильнее» (как сейчас на клавиатуре) — одно правило везде.
4. «Не слишком универсальное» (первая оценка пользователя): если имелась в виду раскладка General MIDI на входе — это правка `processBlock` (таблица нот), отдельная задача с ревью; уточнить у пользователя.
