# Как получить образец drum map (.drm) из Cubase 15

Нужен для задачи T1 (`roadmap.md`): по образцу Claude напишет генератор drum map «Studio600» и «GM → Studio600». Без образца формат не угадывать.

## Шаги

1. Откройте Cubase 15 и любой проект (можно пустой). Добавьте MIDI-трек.
2. Меню **Проект → MIDI → Drum Map Setup…** (в некоторых версиях: **MIDI → Drum Map Setup**).
3. В окне Drum Map Setup нажмите кнопку **New Map** (или выберите существующую карту, например «GM Map»: подойдёт и она).
4. Желательно сделать маленькую свою карту: в списке инструментов поменяйте у двух-трёх строк имя (**Name**), например «Тест 1», «Тест 2», и поставьте у них разные **I-Note** (входная нота) и **O-Note** (выходная нота). Так в образце видно, где что записано.
5. Нажмите **Save** (дискета) в верхней части окна, сохраните файл. Расширение будет `.drm`.
6. Дополнительно, если не сложно: выберите готовую карту «GM Map» и тоже нажмите **Save**, сохранив под другим именем.

## Куда положить

В папку проекта: `Z:\repo\samplit\docs\samples\` (рядом с этим файлом). Имена любые, например `test-map.drm` и `gm-map.drm`.

## Проверка

После сохранения Claude прочитает файл, поймёт структуру XML и проверит, что Cubase открывает сгенерированную карту (потребуется один раз загрузить результат у вас: **Load** в том же окне).

Если пункт меню называется иначе, пришлите скриншот меню **Проект → MIDI**.
