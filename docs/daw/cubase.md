# Samplit в Cubase

> **Статус:** инструкция для основного целевого хоста Cubase 15; до проверки на реальном компьютере не считать сценарии выполненными.

Проверка на живом хосте: Cubase 15, Windows 11, Release-сборка Samplit (VST3). Результаты проверки отмечать в разделе «Статус».

## Перед проверкой

1. Собрать Release и поставить пакеты:
   ```powershell
   .\tools\build.ps1 -Config Release
   .\tools\install_packs.ps1 -SkipBuild
   ```
   Сборка кладёт плагин в папку VST3 пользователя. `install_packs.ps1` нужен только для режима с лицензией и пакетами (`SAMPLIT_LICENSE=ON`); он копирует пресеты и манифесты в `%APPDATA%\Samplit`. Без лицензии в плагине нажмите «Моя библиотека…» и выберите папку `00-Studio600ru-Drum-LIB`.
2. Плагин копируется в `%LOCALAPPDATA%\Programs\Common\VST3`. Туда же попадает и Debug-сборка: в папке лежит та конфигурация, что собрана последней. Для проверки в Cubase последней собрать Release.
3. Если Cubase не видит плагин: Studio → VST Plug-in Manager → Plug-in Paths, добавить эту папку и пересканировать.

## Один стерео-выход

1. Project → Add Track → Instrument, инструмент `Samplit`.
2. В окне плагина слева выбрать пресет «Studio600: Ahead Live» (клик или Enter). Загрузка занимает около 10 секунд, под списком виден ход загрузки. Звук без потерь (float32): из пакетов целиком в память, в режиме «Моя библиотека…» в памяти только начало ударов, остальное читается с диска.
3. Играть с MIDI-клавиатуры или кликом по клавишам в окне плагина. Велосити выбирает удар, а не громкость: тихий и сильный удар звучат по-разному.

## Мульти-аут: каждый микрофон на своей дорожке

1. Studio → VST Instruments (F11), добавить `Samplit` в стойку инструментов. Можно и через Instrument-дорожку: там та же кнопка выходов.
2. У Samplit в стойке нажать кнопку выходов (Activate Outputs) и включить нужные `Out 1` … `Out 15` (все моно). В MixConsole появится по каналу на каждый включённый выход.
3. В окне плагина над микшером пропадёт предупреждение «Отдельные выходы в DAW выключены». Микрофон, выход которого не включён, подписан «→ Main» и играет в общий стерео-выход.
4. В пресете микрофоны уже разведены по выходам: Kick In на Out 1, Kick Out на Out 2, Snare Top на Out 3 и так далее до тома 16" низкого на Out 15. Таблица выходов есть в инструкции пользователя (`tools/dist/guide.html`). Выход меняется в списке над панорамой.

Важно: на отдельном выходе микрофон звучит в полную громкость своего фейдера и без панорамы. Панорама и баланс работают только для сведения в Main.

## Раскладка клавиш (пресет «Ahead Live»)

Нумерация нот как в Cubase: C3 = нота 60.

|---|---|
| Бочка (Pearl Masters) | A-1 … C0 |
| Малый барабан, Ahead Live | C#0 … G#0 |
| Crash 18" | C1 … D#1 |
| Crash 16" | E1 … G1 |
| China 16" | G#1 … A#1 |
| Splash 10" | B1 |
| Хэт (HHX Evolution 14") | C2 … D#4, F#4, G4 |
| Райд (Amedia 22") | C5 … A#5 |

Имя барабана видно в строке над клавиатурой плагина после клика по клавише.

## Что проверить

- [ ] Плагин виден в Cubase, окно открывается, «Моя библиотека…» принимает папку WAV
- [ ] Пресет загружается, у всех трёх пресетов «Все пакеты на месте»
- [ ] Звук с MIDI-клавиатуры, велосити меняет удар
- [ ] Включённые выходы: каждый микрофон на своём канале MixConsole
- [ ] Невключённый выход играет в Main
- [ ] Mute и Solo микрофона, уровень и панорама в Main
- [ ] Сохранить проект, закрыть, открыть: пресет и микшер восстановились
- [ ] Смена пресета во время воспроизведения не даёт щелчков и не роняет Cubase
- [ ] Экспорт (Audio Mixdown) совпадает с тем, что слышно

## Статус
