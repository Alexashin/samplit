# Samplit в Reaper: текущая схема выходов

> **Важно:** прежняя проверка Samplit в Reaper относилась к **8 пэдам / 8 стерео-выходам**. Ниже приведён сценарий для текущего инструмента **Main стерео + 16 моно-выходов**. Успешная реальная проверка именно этой схемы **пока не подтверждена**.

## Установка и обнаружение

1. Собрать Samplit VST3, закрыв DAW с загруженным старым плагином.
2. Проверить путь установки VST3 (`%LOCALAPPDATA%\Programs\Common\VST3` согласно текущему скрипту); если Samplit не появился — Options → Preferences → Plug-ins → VST → Re-scan.
3. Добавить `VST3i: Samplit` на дорожку.

## Основной тест и раздельные микрофоны

1. Загрузить действующий токен и необходимые `.splpack`, выбрать пресет Studio600.
2. Сначала оставить только Main: воспроизвести MIDI-клавиши, проверить общий стерео-микс.
3. В Reaper включить многоканальную маршрутизацию для инструмента и создать дочерние/приёмные дорожки под дополнительные аудиовыходы.
4. Сопоставить **моно**-выходы Samplit `Out 1 … Out 16` отдельным каналам/дорожкам Reaper. Конкретная нумерация каналов FX и автоматическое создание дорожек зависят от версии Reaper: проверить фактическую карту каналов в интерфейсе FX routing, а не использовать старую таблицу стереопар 3/4, 5/6 и т. д.
5. Проверить, что микрофон выходит на выбранную дорожку и не дублируется в Main при активном отдельном выходе. При выключении выхода — fallback в Main.
6. Проверить Solo/Mute, уровень, панораму Main, сохранение и повторное открытие проекта, смену пресетов при воспроизведении.
