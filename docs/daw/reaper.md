# Мульти-аут в Reaper

Проверено: Reaper (x64), Windows 11, сборка Samplit 0.1.0 (VST3). Версию Reaper указать при оформлении записки.

## Установка плагина

Плагин копируется после сборки в `%LOCALAPPDATA%\Programs\Common\VST3`. Эта папка есть в списке путей Reaper по умолчанию. Если плагина нет в списке, откройте Options → Preferences → Plug-ins → VST и нажмите Re-scan.

## Вставка и отдельные выходы

1. Insert → Virtual instrument on new track…, выбрать `VST3i: Samplit (Samplit)`.
2. Reaper при вставке предлагает настроить маршрутизацию под выходы плагина. В проверке выходы раскладывались вручную: 8 дорожек-приёмников, по одной на пэд.
3. Вручную то же самое: Route → Track channels = 18, затем Add new send на приёмную дорожку с источником `3/4`, `5/6`, … и приёмником `1/2`.
4. В окне плагина подпись пэда меняется с `MAIN` на `OUT N`: так плагин показывает, что DAW включила его отдельный выход.

## Соответствие пэдов и каналов

| Пэд | MIDI-нота | Выход | Каналы на дорожке |
|---|---|---|---|
| — | — | Main | 1/2 |
| 1 | 36 | Out 1 | 3/4 |
| 2 | 37 | Out 2 | 5/6 |
| … | … | … | … |
| 8 | 43 | Out 8 | 17/18 |

Если выходы не включены, все пэды играют в Main.

- [x] Режим «всё в Main» без дополнительных выходов
